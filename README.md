# 万能提取 · Chrome 扩展 v1.2.1

v1.2.1 优化抖音分享文案识别、慢网等待与下载重试。v1.2.0 已支持 B 站音视频合并、清晰度选择与网页 MP4 / HLS 导出。原有功能：支持小红书、抖音的图片、视频和平台提供的实况视频，新增微信视频号视频与封面下载。粘贴完整分享文案或短链接、批量提取、预览与勾选下载。纯 Manifest V3 扩展，无需构建、服务器或 API Key。视频号分享解析使用同一 Chrome 中的腾讯元宝登录会话。

## GitHub 下载与安装

- [下载 v1.2.1 扩展安装包](https://github.com/Yatou567/universal-extractor/releases/download/v1.2.1/universal-extractor-chrome-v1.2.1.zip)，解压后按下方步骤安装。
- [查看所有版本](https://github.com/Yatou567/universal-extractor/releases)。
- 也可点击 GitHub 的 **Code → Download ZIP** 下载源码；解压后直接选择包含 `manifest.json` 的仓库根目录。
- GitHub 托管源码和安装包；提取与下载在 Chrome 扩展中完成，无需启动 Mac 本地服务。

## 安装

1. 解压 ZIP，保留 `social-media-downloader` 文件夹。
2. Chrome 地址栏输入 `chrome://extensions`，打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中含 `manifest.json` 的这个文件夹。
4. 在 Chrome 工具栏的拼图菜单中固定「万能提取」。

### 更新现有扩展

1. 解压 Release 中的 `universal-extractor-chrome-v1.2.1.zip`（本地交付包名为 `万能提取-Chrome扩展-v1.2.1.zip`）。
2. 把包内 `social-media-downloader` 文件夹中的全部内容，复制到你原先加载的扩展文件夹，选择替换同名文件。保留原文件夹路径。
3. Chrome 地址栏输入 `chrome://extensions`，打开「开发者模式」，找到原来的「拾光下载」或「万能提取」，点击卡片上的「重新加载」圆形箭头。
4. 若 Chrome 提示新增 B 站权限，查看后启用。确认名称已变为「万能提取」、版本为 **1.2.1**。
5. 关闭旧工作台标签页，刷新抖音或 B 站视频页面，再点击工具栏扩展图标。

更新包是扩展程序，包含 `manifest.json`；之前的「万能提取网页版.zip」不用于更新 Chrome 扩展。原路径更新会继续使用同一个扩展及其本地设置。

安装方式见 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。最低 Chrome 120；建议使用当前稳定版。Edge 可在 `edge://extensions` 使用同样方式加载。

## 使用

- 在**安装插件的同一个 Chrome 配置文件**中登录平台。内置浏览器和 Chrome 的登录状态不共享。
- 刷新首次安装前已打开的作品页，等图片或视频加载。
- 点击扩展图标，在工作台「读取作品页面」；或粘贴分享文案点击「提取媒体」，每批最多 10 个链接。
- 勾选需要的文件后下载。视频封面默认不勾选；图片逐张保存，按原顺序编号。
- 默认目录：`Chrome 下载目录/万能提取/平台/作者_标题_作品ID/`，平台分别为「小红书」「抖音」「微信视频号」。可更改目录名称或开启逐文件选择保存位置。
- 小红书、抖音和视频号的直接下载交给 Chrome 后可以关闭工作台；B 站和 HLS 合并时请保持工作台与原视频页面打开。再次打开可查看本次浏览器会话的进度。

## B 站与网页视频

- 直接在 B 站视频页点击扩展图标；也可在原工作台粘贴一个 BV / av / b23.tv 视频链接，或点击左侧「B站与网页视频」。
- B 站会在扩展内直接读取，不需要采集书签，也不需要启动本地服务器。分析完成后选择清晰度，点击「导出完整 MP4」。
- 原 B 站页面和下载工作台在合并完成前需要保持打开。推荐桌面 Chrome / Edge 勾选「选择保存位置」，大文件直接写入磁盘；不支持写盘的浏览器使用最多 256 MiB 内存保存。
- 获取当前可观看的 H.264 + AAC DASH 音视频，下载全部分段后合并为一个带声音的 MP4。无重编码、无伪改后缀。清晰度取决于当前 B 站播放权限；未登录通常只提供部分档位。
- 不处理试看、付费解锁或 DRM。多 P 视频请使用对应分 P 的网址；页面已切换时需刷新原视频页再分析。
- B 站媒体读取在页面的隔离脚本环境中运行，限定本次捕获的媒体 URL、字节范围、最多四路请求；不读取或导出 Cookie，也不接受任意 URL 代理。
- 其他可跨域的普通 MP4 / 未加密 HLS 可在同一页面解析导出，保留已有纯视频播放功能。公开仓库不预设个人分享站；如需公网分享，可自行部署播放器并在 `video/share-config.js` 中设置 `UNIVERSAL_PLAYER_SITE`。B 站签名视频不提供独立公网分享。
- B 站及网页视频的提取历史保存在扩展页面的本机 localStorage，原平台直接下载的记录仍在旧工作台。地址过期时重新分析。

## 微信视频号

1. 在工作台点击「登录腾讯元宝」，在打开的腾讯官网自行登录。必须是**安装扩展的同一个 Chrome 配置文件**；Codex 内置浏览器中的登录不会同步给 Chrome。
2. 粘贴视频号分享链接，例如 `https://weixin.qq.com/sph/A4MfAMbMob`，点击「提取媒体」。也支持读取已打开的官方 `/finder-preview/pages/sph?id=…` 或带有效 token 的 `/finder-preview/pages/feed?eid=…` 预览页。
3. 扩展先尝试官方分享预览，只有封面时使用元宝的官方链接解析接口获取可播放预览，再读取视频号官方媒体接口。过程中可能打开后台官网标签页；不会发送聊天消息。
4. 提取成功后默认勾选视频，封面可另行勾选。登录过期时会显示「登录腾讯元宝」和「重新读取」。

支持的是官方浏览器预览提供的 H.264 / H.265 视频，优先 H.264。仅有封面、直播、图文或未返回可播放视频的内容不会显示为成功；不支持微信客户端专用的加密流。扩展在提取时读取视频开头少量字节，检查 MP4 文件标识，只保留通过检查的候选地址。此检查用于拦截常见加密、图片和错误响应，不等同于整段音画质量验收。

## 能力与限制

- 完整保留小红书分享链接的安全参数，支持 `/explore/`、`/discovery/item/`、`xhslink.com`；支持抖音 `/video/`、`/note/`、`modal_id` 和 `v.douyin.com` 短链接。
- 微信视频号仅接受 `weixin.qq.com/sph/…` 和指定的官方预览页。公众号文章和视频号创作者后台不在本版本范围内。
- 优先读取页面初始作品状态、JSON 状态和平台本身发出的作品接口响应。必要时读取当前作品播放器和图集 DOM；不会泛扫推荐区域的所有图片。DOM 结果会提示可能需要翻页加载。
- 小红书视频的 `imageList` 可能只是封面，不作为图文笔记误判。
- 视频优先选择带声音的完整 MP4；小红书、抖音和视频号不把分离音轨冒充完整 MP4；B 站 DASH 和网页 HLS 在单独的工作台中合并导出。保留平台返回的媒体内容，不保证无水印。
- 抖音视频优先等待作品数据；仅在播放器已加载视频尺寸且没有播放错误时使用页面媒体兜底。拒绝把作品网页、短链接和 HTML 地址当视频。
- 分享文案兼容 `https\://`、转义斜杠和 HTML 空白实体，保留签名参数。
- 抖音下载失败后点击「重试」，会先重新提取同一作品的最新地址；失败原因直接显示在记录中。
- 下载失败最多切换两个平台提供的备用地址。用户取消、磁盘不足和浏览器安全阻止不会自动重试。
- Chrome 下载状态确认成功；遇到 HTML / JSON 登录响应、错类型媒体或空文件显示失败。
- 媒体地址会过期，失败时应重新读取作品。私密、已删除和账号无权查看的作品不支持。验证码由用户在平台页面完成。
- 本地版本尚未发布 Chrome 商店。平台页面结构变化可能需要更新适配。

## 隐私与权限

无自建服务器、无第三方解析接口、无统计代码、无远程脚本、无 Cookie 读取权限。预览和下载只请求原平台媒体。页面权限限小红书、抖音、官方分享域名、腾讯元宝、视频号预览页、B 站与其媒体域名；腾讯媒体域名权限用于视频文件头校验。

作品信息、分享参数、预览页地址和下载任务暂存在 `chrome.storage.session`（最多 20 个作品），浏览器重启后清除；目录设置保存到 `chrome.storage.local`。平台请求会使用浏览器已有登录状态，扩展不读取或导出 Cookie。视频号解析过程中，分享链接发送到腾讯元宝的官方解析接口，临时预览凭证只用于腾讯官方预览请求；媒体校验不携带账号 Cookie。官方预览标签页地址可能包含短期凭证，请勿转发该地址。

## 开发与验证

源文件均在此目录，运行时零依赖。`node --test tests/*.test.cjs` 运行提取与后台集成测试；测试使用脱敏的结构样本和 Chrome API 模拟。

B 站与网页视频工作台位于 `video/`，`video/extension-adapter.js` 负责 Chrome 隔离页面读取；其余音视频封装模块与网页版共用相同实现，随包附带 mux.js / hls.js 和 Apache-2.0 许可。

主要文件：`lib/core.js` 数据标准化；`lib/wechat.js` 腾讯官方会话解析；`capture.js` 限定作品媒体响应的本地缓存；`extractor.js` 小红书和抖音当前作品提取；`background.js` 标签页、视频号文件校验和下载管理；`app.html` / `app.js` / `app.css` 工作台；`guide.html` 安装指南。

更详细的验收记录见 `VALIDATION.md`。在网页或本地打开 `app.html` 仅显示界面预览，实际提取与下载需作为扩展加载。

请仅保存自己拥有权利或已获授权的内容，并遵守来源平台规则。
