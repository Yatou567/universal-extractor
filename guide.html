GET STARTED

三步，开始下载。

Chrome 扩展 · 无需服务器或 API Key

安装插件

  1. 解压下载包，保留整个 social-media-downloader 文件夹。
  2. 在 Chrome 地址栏输入 chrome://extensions，打开右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的 social-media-downloader 文件夹。然后在工具栏的拼图菜单中固定「万能提取」。

加载方式参考 Chrome 官方安装说明。这份本地版本无需从商店安装。更新旧版时，替换原目录后点击扩展管理页「重新加载」，再刷新工作台；v1.2.1 新增 B 站及媒体域名权限；确认重新加载后版本为 1.2.1。

使用方法

  1. 在同一个 Chrome 浏览器中登录小红书或抖音，打开要下载的作品。首次安装前已经打开的页面，请刷新一次。
  2. 点击工具栏「万能提取」。在工作台中选择作品页面并点击「读取作品页面」，或粘贴一个或多个完整分享文案，点击「提取媒体」。
  3. 预览、勾选图片或视频，点击「下载所选」。在「下载记录」查看完成状态。

默认保存到 Chrome 下载目录 / 万能提取 / 平台 / 作者与标题_作品ID。视频封面可单独勾选，默认下载视频。图文逐张保存，保留图片格式与顺序。

原平台一次最多提取 10 个分享链接；B 站每次一个视频。小红书、抖音和视频号已交给 Chrome 的直接下载可在关闭工作台后继续；B 站合并需要保持工作台和原视频页打开。

B站下载与更新

解压 v1.2.1 扩展包，将 social-media-downloader 文件夹内全部内容替换到原扩展目录，再到 chrome://extensions 点击原扩展的「重新加载」。保留原目录路径，确认版本已变为 1.2.1，并刷新原视频页。

  1. 在 B 站视频页点击工具栏「万能提取」，或点击工作台左侧「B站与网页视频」。
  2. 粘贴一个 B 站链接，点击「开始分析」。无需采集书签或本地服务器。
  3. 选择清晰度，点击「导出完整 MP4」。合并结束前保持原页面与工作台打开。

新增 B 站及媒体域名权限，用于读取当前可观看的视频与封面。支持 H.264 + AAC 音画合并，不处理 DRM 或付费解锁。电脑 Chrome / Edge 推荐使用「选择保存位置」。

微信视频号视频下载

  1. 在工作台点击「登录腾讯元宝」，在安装扩展的同一个 Chrome 配置文件中登录腾讯元宝官网。
  2. 粘贴视频号的 https://weixin.qq.com/sph/… 分享链接，点击「提取媒体」。扩展会通过腾讯官方解析和预览接口读取视频，可能打开后台官网标签页。
  3. 提取成功后预览并下载视频；封面默认不勾选。提示登录过期时，完成登录后点击「重新读取」。

优先保存官方 H.264 预览视频，也接受可用的 H.265。只返回封面、图文或直播时不会标记为视频提取成功。不支持微信客户端专用加密视频；提取时会检查视频文件头，拦截常见错误或加密响应。

元宝仅用于腾讯官方链接解析，不发送聊天消息。Codex 内置浏览器的登录不会同步到原生 Chrome，需要分别登录。

遇到问题

我已经登录，但插件还提示登录

内置浏览器、Chrome、不同 Chrome 配置文件之间的登录状态不共享。请在安装扩展的同一个 Chrome 配置文件里登录，然后打开原链接再读取。小红书分享链接中的安全参数需完整保留。

视频播放正常，但提取不到

首次安装前已打开的页面可能没有媒体响应记录。刷新原作品页面，等播放器加载后重新读取。验证需要在原页面自行完成。

图片数量不完整

结果标注「页面媒体」时可能受懒加载影响；在原页面翻完图片，再重新读取。作品数据提取会直接读取完整图集。

下载失败 / 预览失效

媒体链接会过期。重新读取原作品获取新地址后再下载；网络失败可先点击「重试」。私密、已删除或当前账号无权查看的作品无法提取。

视频分辨率与网页播放不一样

插件选择平台可提供的完整视频文件。小红书、抖音和视频号优先保存带声音的完整 MP4。B 站则在独立工作台中合并 H.264 画面与 AAC 声音。直接保留源文件内容，不处理画面中的水印。

本地处理

插件不使用第三方解析服务，不读取或导出 Cookie。视频号分享链接仅发送给腾讯官方接口，使用浏览器已有登录状态。作品信息和媒体地址仅暂存在当前浏览器会话，浏览器重新启动后需再次提取。下载设置保存在本地。预览与下载会向作品原平台请求媒体。

权限：指定平台页面的读取权限、脚本提取、Chrome 下载管理、本地设置存储。小红书、抖音仅监听作品媒体接口响应；视频号在需要时向腾讯元宝和视频号官网请求预览。不会读取评论和私信作为解析结果。腾讯媒体域名权限用于检查视频文件头。
